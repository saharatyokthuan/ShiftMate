# 📋 ระบบจัดตารางงานพนักงานรายสัปดาห์

เว็บแอปพลิเคชันสำหรับจัดตารางงานพนักงาน 1 สัปดาห์ (จันทร์–อาทิตย์)
ทำงานฝั่ง Client 100% ไม่ต้องใช้ Backend — เก็บข้อมูลใน `localStorage`
รองรับ **มือถือเป็นหลัก** (Mobile-first) และ **Responsive**

---

## ✨ ฟีเจอร์หลัก

| # | ฟีเจอร์ | รายละเอียด |
|---|---|---|
| 1 | **ตารางงานรายสัปดาห์** | เริ่มวันจันทร์–อาทิตย์, View Day / Week / Month |
| 2 | **2 มุมมองตาราง** | (A) แถว=พนักงาน / (B) แถว=ผลัด — สลับได้ด้วยปุ่ม 🔄 |
| 3 | **จัดการพนักงาน** | รหัส(ไม่บังคับ) / ชื่อ-สกุล / ตำแหน่ง / เบอร์โทร + CRUD |
| 4 | **จัดการผลัด** | รหัส / ชื่อ / เวลาเริ่ม-สิ้นสุด / สี / ข้ามวัน / OT / OFF + CRUD |
| 5 | **Assign ผลัด** | แตะ cell → modal เลือกผลัด + ติ๊ก OT + คัดลอกจากเมื่อวาน |
| 6 | **สรุป** | เลือกวันที่ → แสดงจำนวนคนต่อผลัด + ชื่อพนักงาน |
| 7 | **ข้อมูลย้อนหลัง** | ดูข้อมูลย้อนหลังได้ตาม Day / Week / Month |
| 8 | **Backup** | Export / Import ไฟล์ **JSON / CSV / XLSX** |
| 9 | **Reset** | ล้างข้อมูลทั้งหมดใน localStorage |

## 🚀 วิธีใช้งาน

### 1. ติดตั้ง
ไม่ต้องติดตั้งอะไรทั้งสิ้น — แค่มี 3 ไฟล์อยู่ในโฟลเดอร์เดียวกัน

### 2. เปิดใช้งาน

**วิธีที่ 1: เปิดตรง**
```

ดับเบิลคลิก index.html

```

**วิธีที่ 2: ผ่าน Local Server (แนะนำ)**
```bash
# Python
python -m http.server 8080

# Node.js
npx serve

# VS Code
ใช้ Live Server Extension
```

แล้วเปิดเบราว์เซอร์ที่ http://localhost:8080

3. เริ่มใช้งานครั้งแรก

ระบบจะ seed ผลัด 8 รายการ ไว้ให้อัตโนมัติ (ดูตารางด้านล่าง)
จากนั้นทำตามลำดับ:

1. ไปที่เมนู 👤 พนักงาน → เพิ่มพนักงาน
2. ไปที่เมนู 📅 ตารางงาน → แตะ cell → เลือกผลัด
3. ไปที่เมนู 📊 สรุป → ดูสรุป

💡 ผลัดทั้งหมดแก้ไข/ลบ/เพิ่มได้เอง ผ่านเมนู ⏰ ผลัด

---

📐 กฎทางธุรกิจ

· ✅ 1 พนักงาน = 1 ผลัด/วัน (ไม่เช็คเวลาทับกัน เพราะผลัดทับกันโดยธรรมชาติ)
· ✅ OT เก็บเป็น flag ต่อท้ายผลัด → แสดง chip เดียวเป็น M +OT
· ✅ OT checkbox จะโผล่เฉพาะผลัดที่มีการตั้ง otUntil ไว้
· ✅ OFF เป็นผลัดปกติ assign ได้ แสดง chip สีเทา
· ✅ ผลัดข้ามวัน ติ๊กได้ในฟอร์มเพิ่ม/แก้ไขผลัด
· ✅ นับรวมในสรุป จะไม่นับผลัดที่เป็น OFF เป็น "ทำงาน"

---

💾 การสำรองข้อมูล

Export

รูปแบบ รายละเอียด
JSON เก็บทุกอย่างครบ (employees + shifts + schedule) — แนะนำสำหรับ backup
CSV 1 แถว = 1 พนง. × 1 วัน × 1 ผลัด — เหมาะเปิดใน Excel/Sheets
XLSX 3 sheet: Employees / Shifts / Schedule

Import

· รองรับ .json / .csv / .xlsx
· JSON → แทนที่ข้อมูลทั้งหมด
· CSV → แทนที่ทั้งหมด แล้ว parse กลับเป็น employees/shifts/schedule
· XLSX → อ่าน 3 sheet เหมือนตอน export

⚠️ Import จะแทนที่ข้อมูลเดิมทั้งหมด — แนะนำ Export เก็บไว้ก่อน import

🎨 ธีม & การปรับแต่ง

ธีมใช้ CSS Variables ทั้งหมด → แก้ที่ style.css บรรทัดบนสุด

```css
:root {
  --c-primary: #3498db;   /* สีหลัก (ปุ่ม/ไฮไลต์) */
  --c-dark:    #2c3e50;   /* สี Header / Nav */
  --c-bg:      #f4f6f9;   /* สีพื้นหลัง */
  --font-size: 16px;      /* ขนาดตัวอักษรหลัก */
}
```

เปลี่ยนธีมเป็นสีอื่น → แก้ --c-primary ที่เดียว
เปลี่ยนเป็น Dark mode → ปรับ --c-bg / --c-text / --c-white

🔒 ความปลอดภัยของข้อมูล

· ข้อมูลทั้งหมดเก็บใน เบราว์เซอร์ของคุณเท่านั้น (localStorage)
· ไม่มีการส่งข้อมูลออกอินเทอร์เน็ต ยกเว้นการโหลดฟอนต์และ SheetJS
· ข้อมูลจะหายถ้า:
  · ล้าง Browser Cache / Data
  · ใช้โหมด Incognito
  · กดปุ่ม "ล้างข้อมูลทั้งหมด"
  · เปลี่ยนเบราว์เซอร์ / อุปกรณ์

💡 แนะนำให้ Export JSON เก็บไว้เป็นประจำ เพื่อป้องกันข้อมูลสูญหาย

❓ คำถามที่พบบ่อย (FAQ)

Q: ทำไมเพิ่มพนักงานแล้วไม่เห็นในตาราง?
A: ลองรีเฟรชหน้าเว็บ (F5) หรือตรวจสอบว่ากด "บันทึก" ในฟอร์มแล้ว

Q: Assign ผลัดซ้ำในวันเดียวได้ไหม?
A: ไม่ได้ — ระบบบังคับ 1 คน 1 ผลัด/วัน ถ้าเลือกใหม่จะแทนที่ของเดิม

Q: ลบพนักงานแล้วตารางงานหายไหม?
A: หาย — ระบบลบข้อมูล schedule ของพนักงานคนนั้นทั้งหมด (มี confirm ก่อนลบ)

Q: Excel export แล้วภาษาไทยเป็นตัวต่างดาว?
A: ระบบใส่ BOM \uFEFF ไว้แล้ว — ถ้ายังเพี้ยนให้ Import ผ่าน Google Sheets แทน

Q: อยาก backup ข้อมูลย้ายไปเครื่องอื่น ทำยังไง?
A: Export JSON → ส่งไฟล์ไป → Import JSON บนเครื่องปลายทาง

Q: Reset แล้วกู้คืนได้ไหม?
A: ไม่ได้ — ข้อมูลจะหายถาวร ควร Export ก่อน
